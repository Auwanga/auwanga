## 🧠 About Me

I'm **Auwanga Enkali**, a Namibian technology innovator, founder and full-stack developer building products at the intersection of **AI, software infrastructure, mobile technology and real-world problems**.

I started building software as a teenager and have since gone from experimenting with code to building and deploying systems used in real environments.

Today, I build through **EnkaliPrime**, a youth-led Namibian technology company focused on creating practical technology for Africa and beyond.

My work is particularly interested in one question:

> **How do we build technology that still works when the environment isn't perfect?**

That means thinking about connectivity, infrastructure, language, accessibility, cost and the realities people actually face.

### Currently

* Founder & builder at **EnkaliPrime**
* **Mr STEM Namibia 2026**
* Building AI-powered and offline-first systems
* Developing mobile and web platforms
* Working with cloud infrastructure and modern full-stack architectures
* Studying Computer Science
* Exploring AI agents, local inference, developer infrastructure and African technology

### Building technology that works where it matters most.

</div>

**EnkaliPrime** is a Namibian technology company and innovation hub focused on building practical digital systems across AI, communications, mobility and software infrastructure.

The goal isn't to build technology simply because it is technically impressive.

The goal is to build technology that **solves something.**

### Current Product Ecosystem

#### ⚡ Kinetic

**AI-powered communications infrastructure.**

Kinetic is being built beyond the concept of a simple chatbot. It provides infrastructure for businesses and developers to build intelligent communication experiences across channels.

* AI-powered conversations
* WhatsApp commerce
* SMS infrastructure
* Developer APIs
* SDK architecture
* Communication automation
* AI agents
* Dashboard and monitoring infrastructure

> **Kinetic is infrastructure for intelligent communication.**

---

#### 🚗 NamRides

**Long-distance ride booking built for Namibia.**

NamRides is designed around the realities of long-distance travel in Namibia, connecting passengers and drivers while reducing the uncertainty and chaos surrounding informal long-distance transport.

* Mobile-first experience
* React Native + Expo
* Mapbox integration
* Driver and passenger workflows
* Ride scheduling
* Booking infrastructure
* Designed around Namibia's transport ecosystem

> **Making long-distance travel more predictable.**

---

#### 🧠 Nexus

**Offline-first AI infrastructure.**

Nexus explores how powerful AI experiences can be delivered without relying entirely on cloud connectivity.

The platform is focused on:

* Local AI inference
* Voice interaction
* Offline assistants
* Local models
* Text-to-speech
* Intelligent actions
* Edge deployment
* Resource-efficient systems

> **If it doesn't work offline, it isn't finished.**

---

#### 🗣️ Oshindonga Translation API

An API focused on making African language technology more accessible to developers.

Features include:

* Oshindonga ↔ English translation
* Large language dictionary
* Fuzzy matching
* POS-aware processing
* Confidence scoring
* AI-assisted processing
* OCR integration

---

#### 📚 Nam-Policies

An AI-powered retrieval system for navigating Namibian policy and public information.

Built around:

* Document ingestion
* PDF processing
* Semantic search
* Vector databases
* Retrieval-Augmented Generation
* AI-powered question answering
